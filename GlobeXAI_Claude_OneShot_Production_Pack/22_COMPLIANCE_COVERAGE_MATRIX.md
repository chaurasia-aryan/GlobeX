# Compliance Coverage Matrix

## Purpose

Make system coverage explicit.

Dimensions:

- origin;
- destination;
- HS6;
- product category;
- sanctions jurisdiction;
- export-control regime;
- import-control regime;
- source freshness.

Example:

| Dimension | Covered | Source | Freshness | Decision |
|---|---|---|---|---|
| India export | YES | DGFT | current | automated |
| Destination import | PARTIAL | official customs | stale | review |
| End use | PARTIAL | rule set | current | review |

Never represent partial coverage as full coverage.
