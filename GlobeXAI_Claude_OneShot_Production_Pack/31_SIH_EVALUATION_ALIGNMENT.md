# SIH Evaluation Alignment

The supplied first-round rubric emphasizes:
- problem understanding;
- root-cause analysis;
- literature/existing solutions;
- valid citations;
- problem-solution fit;
- innovation;
- feasibility/impact.

The submission guidance requires exactly nine slides and a 5–7 minute video, with evidence-based visuals and traceable references. It also explicitly warns against fabricated/unverifiable references and unsupported claims such as "first", "unique" or "100%". fileciteturn15file0

## Implementation consequence

The final project must generate evidence for:
- problem;
- existing solutions;
- model validation;
- architecture;
- compliance coverage;
- data provenance;
- measurable results;
- limitations.

Do not manufacture results for the PPT.

If a component is a prototype:
label it as prototype.

If a source is unavailable:
label it unavailable.

If a model performs poorly:
report it.

The PPT/video should show original architecture, real experiment outputs, citations, and feasibility rather than decorative AI-generated visuals.
