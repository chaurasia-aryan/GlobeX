# Directory Safety Rules

1. NEVER DELETE.
2. NEVER OVERWRITE.
3. NEVER RESET OR DISCARD GIT CHANGES.
4. NEVER MOVE A FILE WITHOUT INSPECTING ITS ROLE.
5. RECORD EVERY MOVE/RENAME.
6. UPDATE EVERY AFFECTED REFERENCE.
7. VERIFY FILE COUNTS AND CHECKSUMS AFTERWARD.
8. PRESERVE DUPLICATES; classify them instead of deleting them.
9. Preserve backend runtime copies unless proven unnecessary.
10. If uncertain, leave the file where it is rather than making a destructive assumption.
