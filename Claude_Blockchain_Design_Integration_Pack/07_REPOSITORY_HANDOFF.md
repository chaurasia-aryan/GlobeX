Do not assume either repository's contents.

Resolve the exact repository first.

Record:

- repository URL;
- branch;
- commit SHA used for the audit;
- date/time inspected.

If the repository changes during implementation, record the new commit SHA and explain why the change was used.

Never treat an unverified repository name as evidence of implementation details.
